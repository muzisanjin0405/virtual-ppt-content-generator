# 内容形态伪随机规则

本文件用于控制一套虚拟 PPT 的页面文字形态变化。它只影响内容组织，不输出视觉设计建议。

## 1. 核心原则

不要把每页固定成“标题 + 一段正文 + N 个 bullet”。真实 PPT 中会自然混合长文本、短句、数据、表格、流程、纯标题展示等页面。

正文不设统一字数上下限。标题继续遵守 8–16 字规则（固定专名除外）。

## 2. 受控伪随机，而不是纯随机

内部先用“场景 + 行业 + 页数 + 项目名”形成一个稳定的伪随机种子概念，再从当前场景允许的内容形态池中选择。

选择顺序：

1. 先判断页面任务是否有硬结构：流程、预算、KPI、产品矩阵等；
2. 无硬结构时，再从场景允许的形态池中做变化；
3. 避免同一形态连续 3 页以上；
4. 不为了变化而改变业务含义；
5. 不为了项数均衡拆掉长文本页或给展示页补正文。

## 3. 内容形态池

- Title Only：标题-only，0 项
- Narrative Longform：标题 + 一段完整长文本，1 项
- Narrative Short：标题 + 短说明，1 项
- Single Focus：标题 + 单一完整信息，1 项
- Parallel Points：标题 + 3–6 个并列项
- Binary Contrast：标题 + 2 项，只用于真实二元关系
- Data Facts：标题 + 若干核心数据
- Table / Matrix：标题 + 表格 / 矩阵
- Case Narrative：标题 + 完整案例或阶段信息
- Process / Timeline：标题 + 3 个以上步骤 / 阶段
- Quote / Claim：标题 + 一句主张 / 引语，可视为 1 项

## 4. 场景权重倾向

### 企业 / 产品介绍
高：Narrative Longform、Single Focus、Product / Matrix、Data Facts
中：Parallel Points、Case Narrative、Title Only
低：流程，除非服务 / 交付确有流程

建议：篇幅足够时，通常至少自然出现一次完整长文本叙述页。

### 招商 / 合作展示
高：Data Facts、Parallel Points、Policy、Business Model、Case Narrative
中：Narrative Short、Single Focus、Process
低：Title Only；除封面、章节、产品展示外不要过多留白

### 营销 / 策划方案
高：Problem、Audience、Strategy、Process / Timeline、KPI、Budget
中：Narrative Short、Data Facts、Case Narrative
低：Narrative Longform，除项目背景或策略总述

### 内部 / 对外汇报
高：Data Facts、Review、Process、Timeline、Single Focus
中：Narrative Short、Table / Matrix
低：Title Only

### 洞察报告 / 白皮书
高：Narrative Longform、Data Facts、Comparison、Table / Matrix
中：Single Focus、Quote / Claim
低：Title Only，除章节页

### 顾问方案
高：Problem、Strategy、Process、Data Facts、Table / Matrix
中：Narrative Longform、Case Narrative
低：Title Only

### 培训课件
高：Single Focus、Parallel Points、Process、Case / Example
中：Narrative Short、Quote / Claim、Title Only章节页
低：超长连续叙述，除定义 / 前言确有必要

### 求职简历
高：Single Focus、Parallel Points、Data Facts、Case
中：Narrative Short
低：Narrative Longform、Title Only

### 作品展示 / Portfolio
高：Title Only、Single Focus、Case Narrative
中：Narrative Longform（项目背景 / 复盘）、Data Facts
低：密集表格和多层 bullet

建议：纯作品展示页应自然出现若干次；具体数量由项目数量和页数决定，不设硬比例。

### 社交名片
高：Title Only、Single Focus、Parallel Points
低：Narrative Longform、复杂表格 / 流程

## 5. 项数与内容形态的关系

- Title Only：0 项；
- Narrative Longform：1 项；
- Narrative Short：1 项；
- Single Focus：1 项；
- Binary Contrast：2 项；
- Parallel Points：通常 3–6 项；
- Process / Timeline：至少 3 项；
- Data / Matrix：按真实信息数量决定。

“项数平均”只针对适合并列组织的页面。不要为了让统计更漂亮，把叙述页拆碎或给展示页添加无意义文字。
