# 行业知识模块

本文件用于决定“这个行业的真实 PPT 应该出现哪些专业内容、指标、对象与语言”。

原则：选择与当前场景有关的模块，不要把整个行业知识包全部塞进一份 PPT。

---

# 1. 消费与零售

## 细分行业
食品饮料、茶饮、咖啡、美妆护肤、服饰时尚、家居生活、宠物、新消费品牌、零售连锁。

## 常见业务对象
消费者、经销商、门店、商超、便利店、电商平台、企业采购、加盟商。

## 专业内容模块
- 消费趋势
- 人群分层
- 消费场景
- 产品矩阵 / SKU
- 英雄产品
- 配方 / 原料 / 风味 / 材质
- 价格带
- 包装规格
- 渠道结构
- 铺货与动销
- 客单价
- 复购
- 连带率
- 毛利率
- 经销折扣
- 返利
- 起订量
- 库存周转
- 促销机制
- 供应链
- 生产与品控
- 季节性
- 礼赠
- 会员
- 社媒内容

## 常用模拟指标
GMV、销售额、同比增长、SKU 数、合作终端数、覆盖城市、复购率、月均动销、客单价、毛利率、渠道占比、会员数、库存周转天数。

## 茶饮 / 茶叶额外字段
茶类、产区、采摘季、原叶等级、拼配、焙火、冷萃、茶包材质、冲泡方式、克重、礼盒规格、食品检测、企业团购、节庆销售。

## 咖啡额外字段
产区、豆种、处理法、烘焙度、风味、咖啡豆 / 挂耳 / 冻干 / 即饮、门店模型、杯量、日均出杯。

## 美妆额外字段
肤质、功效诉求、配方成分、产品测试、价格带、内容种草、转化、复购、渠道。

# 2. 科技与互联网

## 细分行业
AI、SaaS、企业软件、消费 App、互联网平台、智能硬件、开发者工具。

## 常见业务对象
企业客户、IT 部门、业务部门、开发者、普通用户、渠道伙伴、投资人。

## 专业内容模块
- 行业变化 / Why Now
- 用户工作流
- 痛点
- 产品架构
- 功能体系
- AI / 模型能力
- 数据流
- API / 集成
- 部署方式
- 权限
- 安全
- 稳定性
- 实施周期
- 效率提升
- ROI
- 用户增长
- 活跃度
- 留存
- 付费转化
- ARR / MRR
- 客户数
- 客单价 ACV
- CAC / LTV
- NRR / GRR
- 服务支持
- 路线图

## 常用模拟指标
ARR、MRR、同比增长、付费客户数、DAU / MAU、付费转化率、留存率、NRR、CAC、LTV、部署周期、故障率、SLA、工时节省、ROI。

## AI SaaS 额外字段
模型能力、上下文、知识库、Agent / 工作流、推理成本、人工替代率、准确率 / 命中率（仅作为虚拟指标时谨慎使用）、部署与数据隔离。

# 3. 金融与专业服务

## 细分行业
金融、保险、投资、咨询、法律、会计、人力资源服务。

## 常见业务对象
企业管理层、投资人、机构客户、高净值客户、专业部门。

## 专业内容模块
- 市场环境
- 客户问题
- 风险
- 决策框架
- 方法论
- 服务范围
- 项目流程
- 行业 Benchmark
- 方案比较
- 投资逻辑
- 财务指标
- 合规要求
- 专家团队
- 交付模型
- 服务费用
- 案例

## 常用模拟指标
项目金额、回报率、成本节约、周期、客户续约、AUM、转化率、风险敞口、咨询项目里程碑。

## 注意

# 4. 医疗健康

## 细分行业
医疗服务、医药、医疗器械、诊断、数字医疗、健康管理。

## 常见业务对象
患者、医生、医院、药店、经销商、企业健康客户、投资人。

## 专业内容模块
- 未满足需求
- 患者 / 医生旅程
- 临床流程
- 产品原理
- 产品组合
- 使用场景
- 安全性
- 质量体系
- 合规路径
- 医疗服务流程
- 专业团队
- 渠道与服务网络
- 供应链
- 证据
- 项目效果

## 常用模拟指标
服务人数、随访率、预约转化、交付周期、设备部署量、服务网点、满意度、复诊率等。

## 硬性限制
虚拟项目可以编经营数据，但不要虚构真实监管审批、真实临床试验结论、真实官方认证或医疗疗效承诺。

# 6. 制造与产业

## 常见业务对象

## 专业内容模块
- 行业变化
- 产品 / 系统
- 技术参数
- 研发能力
- 生产工艺
- 产线
- 产能
- 良率
- 供应链
- 质量控制
- 交付能力
- 成本
- 能耗
- 服务网络
- 客户案例
- 路线图

## 常用模拟指标
产能、良率、交付周期、成本降低、能耗降低、设备 OEE、产线效率、订单额、客户数、覆盖区域。

# 8. 公共与文化

## 细分行业
政务、公共服务、城市宣传、文化机构、博物馆、艺术机构、公益、城市品牌。

## 常见业务对象

## 专业内容模块
- 项目背景
- 政策 / 城市背景（仅作为虚构政策时避免冒充真实文件）

- 文化资源
- 项目体系
- 服务流程
- 利益相关方
- 活动
- 传播
- 社会影响

## 注意
不要虚构现实政府文件、真实官方批复或真实领导背书。

# 9. 个人 / 创意职业与作品集扩展

当“个人成长 / 作品展示”与设计、创意、摄影、建筑、UI、品牌等行业组合时，可调用：

- 个人定位
- 技能组合
- 项目类型
- 客户背景（虚构）
- 项目周期
- 项目目标
- 角色职责
- 限制条件
- 关键决策
- 方案变化
- 交付物
- 结果数据
- 复盘

常用模拟结果：上线周期、转化率提升、审批轮次减少、交付效率、资产数量、覆盖渠道、用户反馈等。
