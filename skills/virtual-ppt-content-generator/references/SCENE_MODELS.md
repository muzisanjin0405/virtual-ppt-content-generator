# 场景模型库

本文件定义场景兼容、真实业务问题、默认受众、默认目标和推荐叙事顺序。

原则：**场景决定这份 PPT 必须回答什么，而不是决定一套固定页标题。**

---

# A. 商业交流

## A1. 企业 / 产品介绍

### 常见别名
公司介绍、企业介绍、品牌介绍、产品介绍、产品推介、公司宣传、品牌 Deck、销售介绍。

### 默认受众
潜在客户、合作伙伴、采购方、渠道方。

### 默认目标
建立认知与信任，证明产品 / 服务价值，促成下一步沟通。

### 必须回答的问题
1. 我们是谁，处于什么阶段？
2. 为什么这家公司 / 品牌存在？
3. 服务什么客户或用户？
4. 核心产品 / 服务是什么？
5. 产品之间如何形成体系？
6. 哪些能力形成真正差异？
7. 有什么事实、项目或数据证明？
8. 如何交付 / 服务？
9. 适合怎样的合作对象？
10. 下一步如何联系或合作？

### 推荐叙事
身份与定位 → 市场 / 客户问题 → 产品 / 服务体系 → 核心能力 → 典型场景 → 案例 / 数据 → 服务体系 → 合作方式 → 下一步

### 内容注意
- 不要前 5 页都讲愿景、使命、价值观。
- 产品页应有真实规格、能力、适用对象或价值，而不只是形容词。
- 企业历程只在能解释能力积累时保留。
- 可自然出现 1 页“标题 + 一段完整长文本”的企业概述 / 品牌叙述页；这类页面不要为了项数均衡拆成 bullet。
- 其他页面继续按真实任务变化内容形态，不要求统一格式。

## A2. 招商 / 合作展示

### 常见别名
招商方案、招商手册、渠道招商、代理商招募、加盟合作、城市合伙人、经销商合作、渠道合作、大客户合作。

### 默认受众
区域经销商、渠道商、加盟商、企业采购、战略合作伙伴。

### 默认目标
降低合作顾虑，让对方相信“有市场、卖得动、赚得到、风险可控”，推动签约或进一步洽谈。

### 必须回答的问题
1. 为什么现在值得进入这个市场？
2. 品牌 / 项目抓住了什么机会？
3. 产品具体卖给谁？
4. 产品为什么能形成复购或持续需求？
5. 产品组合是否足以支撑渠道经营？
6. 现在已经验证到什么阶段？
7. 哪些渠道表现最好？
8. 合作伙伴靠什么赚钱 / 获得价值？
9. 首次投入、价格、毛利、返利、库存如何设计？
10. 总部 / 项目方提供哪些实际支持？
11. 区域、价格、供货、售后等风险如何降低？
12. 合作流程是什么？

### 推荐叙事
市场机会 → 品牌 / 项目定位 → 用户与需求 → 产品体系 → 核心单品 / 方案 → 经营验证 → 渠道表现 → 盈利逻辑 → 合作政策 → 支持体系 → 风险保障 → 合作流程 / CTA

### 内容注意
- 商业信息不能全部拖到最后 3 页。
- 需要真实感的价格、折扣、返利、起订量、交付周期等细节。
- 不要只有“我们很好”，必须回答“合作方为什么值得做”。

## A3. 营销 / 策划方案

### 常见别名
营销方案、推广方案、传播方案、品牌策划、新品上市、整合营销、活动策划、年度营销规划。

### 默认受众
品牌方、市场部、业务负责人、项目决策者。

### 默认目标
证明问题判断准确、策略可行、执行可落地，并争取预算 / 项目批准。

### 必须回答的问题
1. 项目背景与业务目标是什么？
2. 当前真正的问题是什么？
3. 市场和竞品发生了什么变化？
4. 用户是谁，其行为和动机是什么？
5. 哪个洞察最值得转化为策略？
6. 本次营销目标如何量化？
7. 总策略是什么？
8. 核心创意 / 传播主张是什么？
9. 内容、渠道、活动如何协同？
10. 项目如何分阶段执行？
11. 预算如何分配？
12. KPI 如何衡量？
13. 有什么风险与优化预案？

### 推荐叙事
背景 → 现状 → 问题定义 → 市场 / 竞品 → 用户洞察 → 目标 → 策略总纲 → 创意主张 → 内容 / 渠道 / 活动 → 节奏 → 预算 → KPI → 风险 → 总结

### 内容注意
- 禁止“先列抖音、小红书、公众号”再补策略。
- 渠道只是执行层，洞察与策略必须在前。
- KPI 要与目标同口径。

# B. 项目汇报

## B1. 内部汇报 / 工作总结

### 常见别名
年度总结、季度总结、月度总结、工作汇报、部门汇报、述职、阶段总结。

### 默认受众
直属领导、部门管理层、跨部门负责人。

### 默认目标
让决策者快速知道“做了什么、结果如何、问题是什么、下一步要什么资源或决策”。

### 必须回答的问题
1. 本周期承担了哪些目标？
2. 哪些结果已经完成？
3. 哪些指标超预期 / 未达成？
4. 哪些工作最有业务价值？
5. 资源使用与协作情况如何？
6. 当前最大问题是什么？
7. 问题的真实原因是什么？
8. 下阶段优先级如何调整？
9. 需要管理层做什么决策或支持？

### 推荐叙事
执行摘要 → 目标回顾 → 核心结果 → 重点工作 → 数据 → 偏差 → 原因 → 改进 → 下阶段计划 → 资源 / 决策需求

### 内容注意
- 先结论后过程。
- 不要把“做过的事情”当成“成果”。
- 结果尽量量化。

---

## B2. 内部汇报 / 项目复盘

### 常见别名
项目复盘、活动复盘、版本复盘、营销复盘、上线复盘、失败复盘、成功复盘。

### 默认受众
项目团队、管理层、相关协作部门。

### 默认目标
解释目标与结果差距，总结可复用经验，并形成下一轮行动。

### 必须回答的问题
1. 项目原始目标与假设是什么？
2. 最终结果是什么？
3. 哪些结果达到 / 超过 / 未达到？
4. 哪些关键节点影响最终结果？
5. 成功因素是什么？
6. 失败或偏差原因是什么？
7. 哪些结论可以复用？
8. 哪些流程需要改变？
9. 下一轮具体如何做？

### 推荐叙事
目标与假设 → 执行路径 → 结果 → 差距 → 关键节点 → 做对的事 → 做错的事 → 根因 → 经验沉淀 → 改进动作 → 下一轮

---

## B3. 对外汇报 / 客户汇报

### 常见别名
客户汇报、阶段汇报、项目进展、交付汇报、结案汇报、客户提案复盘。

### 默认受众
客户项目负责人、采购、业务负责人、管理层。

### 默认目标
建立专业信任，证明项目推进与交付价值，并确认下一阶段行动。

### 必须回答的问题
1. 双方最初目标是什么？
2. 本阶段完成了什么？
3. 交付物是什么？
4. 已产生哪些结果？
5. 哪些变化值得客户关注？
6. 当前风险 / 待确认事项是什么？
7. 下一阶段做什么？
8. 需要客户确认什么？

### 推荐叙事
合作背景 → 目标 → 工作范围 → 本阶段动作 → 交付成果 → 数据 / 效果 → 重点案例 → 风险与待确认 → 下一阶段 → 客户决策事项

### 内容注意
- 不暴露无必要的内部琐碎过程。
- 异常和风险必须有处理建议。

---

## B4. 对外汇报 / 投融资 BP

### 常见别名
BP、商业计划书、融资路演、投资人 Deck、创业计划书、Investor Deck。

### 默认受众
投资机构、产业资本、战略投资方。

### 默认目标
证明这是一个足够大、正在被验证、可持续扩张且值得投入资本的机会。

### 必须回答的问题
1. 解决的核心问题是什么？
2. 市场为什么现在发生？
3. 产品 / 服务是什么？
4. 用户为什么需要？
5. 商业模式如何赚钱？
6. 市场空间多大？
7. 当前 traction 是什么？
8. 增长靠什么驱动？
9. 竞争壁垒是什么？
10. 团队为什么能做成？
11. 单位经济模型是否健康？
12. 未来 2–3 年如何增长？
13. 融资金额与用途是什么？

### 推荐叙事
问题 → Why Now → 解决方案 → 产品 → 市场 → 商业模式 → Traction → 增长引擎 → 竞争与壁垒 → 单位经济 → 团队 → 规划 → 融资需求

### 内容注意
- 不是品牌宣传册。
- 数据应具有投资人可判断性：收入、增长、毛利、CAC、LTV、留存、现金消耗等，按行业选择。

## B5. 对外汇报 / 战略推介

### 常见别名
战略推介、项目推介、战略合作提案、战略规划展示、产业推介。

### 默认受众
合作方高层、政府 / 园区 / 产业伙伴、战略客户。

### 默认目标
让对方理解机会、战略路径、双方资源互补与合作收益。

### 必须回答的问题
1. 当前战略背景是什么？
2. 机会窗口在哪里？
3. 本项目战略定位是什么？
4. 重点业务 / 项目如何组合？
5. 双方资源如何互补？
6. 分阶段目标是什么？
7. 收益与影响是什么？
8. 需要怎样的合作机制？
9. 下一步如何启动？

### 推荐叙事
战略背景 → 机会 → 定位 → 核心项目 → 资源匹配 → 合作机制 → 阶段目标 → 预期价值 → 启动计划

---

## B6. 洞察报告 / 行业分析

### 常见别名
行业研究、市场研究、行业趋势、赛道分析、市场洞察、竞争格局。

### 默认受众
管理层、投资人、业务团队、行业客户。

### 默认目标
通过证据回答“市场发生了什么、为什么、接下来意味着什么”。

### 必须回答的问题
1. 研究范围与口径是什么？
2. 市场规模和结构如何？
3. 增长来自哪里？
4. 主要玩家如何分布？
5. 用户 / 客户行为如何变化？
6. 哪些趋势正在形成？
7. 哪些判断是噪音，哪些值得关注？
8. 哪些机会 / 风险对业务最重要？
9. 建议采取什么动作？

### 推荐叙事
研究框架 → 市场概览 → 结构 → 增长驱动 → 竞争 → 用户 → 趋势 → 核心洞察 → 机会 / 风险 → 建议

### 内容注意
- 虚拟报告允许构建模拟研究数据，但样本、时间、口径必须一致。

---

## B7. 洞察报告 / 数据研究

### 常见别名
数据报告、用户数据分析、经营分析、消费数据研究、调研报告。

### 默认受众
业务团队、管理层、研究客户。

### 默认目标
从数据中形成可行动的结论，而不是堆图表。

### 必须回答的问题
1. 数据来自什么模拟样本 / 时间区间？
2. 最重要的变化是什么？
3. 哪些群体 / 渠道 / 产品差异显著？
4. 哪些指标存在关联？
5. 数据背后可能的原因是什么？
6. 对业务有什么影响？
7. 下一步应验证什么？

### 推荐叙事
研究问题 → 样本与口径 → 总体数据 → 关键分组 → 变化 / 关联 → 解释 → 洞察 → 建议 → 下一步验证

---

## B8. 洞察报告 / 白皮书发布

### 常见别名
行业白皮书、趋势白皮书、年度报告、研究发布、产业报告。

### 默认受众
行业从业者、媒体、客户、政策 / 产业相关人员。

### 默认目标
建立系统性观点与专业权威，给出可引用的行业结论。

### 必须回答的问题
1. 为什么要研究这个问题？
2. 研究方法与样本是什么？
3. 行业基础盘是什么？
4. 有哪些结构性变化？
5. 用户 / 企业行为如何变化？
6. 关键趋势有哪些？
7. 典型案例说明什么？
8. 未来情景如何？
9. 对不同角色意味着什么？

### 推荐叙事
前言 → 研究方法 → 行业基础 → 核心发现 → 分主题研究 → 案例 → 趋势 → 未来情景 → 行动建议 → 结语

# C. 知识变现

## C1. 顾问方案

### 常见别名
咨询方案、Consulting Proposal、咨询提案、顾问提案、诊断方案、咨询项目建议书。

### 默认受众
企业决策者、项目负责人、创业者、专业客户。

### 默认目标
证明诊断准确、方法可信、方案可执行，并促成顾问 / 咨询合作。

### 必须回答的问题
1. 客户当前处于什么状态？
2. 真正问题是什么？
3. 根因是什么？
4. 应采用什么分析框架？
5. 哪些策略优先级最高？
6. 方案包含哪些工作流 / 模块？
7. 预计如何产生结果？
8. 项目如何推进？
9. 双方分别需要投入什么？
10. 合作周期与交付是什么？

### 推荐叙事
现状 → 诊断 → 根因 → 方法框架 → 策略 → 方案模块 → 路线图 → 交付 → 预期价值 → 合作方式

4. 方法 / 框架是什么？

6. 有什么案例？
7. 常见错误是什么？
8. 如何练习 / 应用？
9. 最后应记住什么？

### 推荐叙事
学习目标 → 问题 → 核心概念 → 框架 → 分步方法 → 案例 → 练习 → 常见错误 → 总结 → 行动

# D. 个人成长

## D1. 求职简历

### 常见别名
PPT 简历、求职简历、个人介绍、面试 Deck、个人履历。

### 默认受众
招聘经理、业务负责人、面试官。

### 默认目标
证明“我与目标岗位匹配，并且有事实证明能产生结果”。

### 必须回答的问题
1. 我是谁，目标岗位是什么？
2. 核心能力有哪些？
3. 经历如何形成这些能力？
4. 有哪些量化成果？
5. 哪些项目最能证明岗位匹配？
6. 我的工作方法是什么？
7. 为什么适合这个岗位 / 团队？
8. 如何联系？

### 推荐叙事
定位 → 简介 → 能力 → 经历 → 成果 → 代表项目 → 方法 → 岗位匹配 → 联系方式

### 虚构要求
若用户要求虚拟简历，人物年龄、教育、工作年份、岗位晋升、项目年份必须严格一致。

2. 为什么选这些项目？
3. 每个项目的真实背景是什么？
4. 任务和限制是什么？
5. 关键判断是什么？
6. 做了什么？
7. 结果如何？
8. 有什么复盘与能力沉淀？

### 推荐叙事
个人定位 → 精选项目概览 → 项目 A 背景 / 目标 / 过程 / 结果 → 项目 B → 项目 C → 方法总结 → 联系方式

### 内容注意
- 每个项目整体上仍需要“背景—任务—决策—结果”，不要只写“设计理念”。
- 但项目内部允许插入若干纯作品展示页：这些页面只保留作品 / 项目标题，不输出正文、要点或说明，让作品视觉本身承担信息。
- 纯作品展示页的文本项数视为 0，不参与普通内容页的项数均衡。
- 作品信息页与纯展示页应交错出现，不要求每一页都承担解释任务。
- 虚拟项目可以生成品牌、客户、周期、目标和成果数据，但应保持项目可执行性。

## D3. 社交名片

### 常见别名
社交名片、个人介绍 Deck、个人名片 PPT、个人主页、合作名片。

### 默认受众
潜在合作方、客户、同行、社交关系。

### 默认目标
让对方在极短时间理解“我是谁、我能做什么、为什么值得联系”。

### 必须回答的问题
1. 我是谁？
2. 我主要做什么？
3. 我最擅长什么？
4. 有什么代表成果？
5. 适合什么合作？
6. 如何联系？

### 推荐叙事
个人定位 → 能力 → 代表成果 → 合作方向 → 联系方式

### 内容注意
- 页数短。
- 文字必须高度浓缩。
